Solution access
Global switches that apply to every user. Read off: nobody can open or download that solution. Download off: people can still view it but can't download it as PDF or HTML. Users keep their assignments, so switching back on restores access. Admin always sees everything. When a contributor uploads a newer version of a solution, both versions show, marked v1, v2…; Use latest hides the older ones and gives their users the newest.
