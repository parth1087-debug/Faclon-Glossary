Layer 8Visibility

The visibility platform: custom dashboards, reports and alerts, with App Studio for building apps.

Layer 7Agents

The agent factory and harness. It works with any AI model, agent or MCP server, runs multi-agent work and the platform co-pilots, and hosts the MCP Gateway, a cluster of MCP connectors with semantic search over tools.

Layer 6Ontology

A live model of the operation: object types, properties, links, actions and logic that apps, models and agents share.

Layer 5Models

Builds and serves every model type, including optimisation, computer vision and local LLMs.

Layer 4Data

The data platform: time-series, documents, vector and graph data and app inputs, served through an API gateway.

Layer 3Governance

Governs users, sign-in, access, policies and the audit trail across every Faclon product.

Layer 2Integration

Usually runs in the DMZ. It connects every OT system over 20+ industrial protocols, keeps a local buffer and backup, streams the data into UDF, and can write approved setpoints back.

Layer 1Deployment

Deploys the entire stack on any public or private cloud, or natively on the customer's own servers, with Kubernetes, Docker and CI/CD.
